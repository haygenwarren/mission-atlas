# Fonts for generated images

Static copies of the site's two typefaces, for the link-preview images drawn on
the server (`src/app/missions/[slug]/opengraph-image.tsx`). The image renderer
cannot read variable fonts or WOFF2, which is what the pages themselves use.

| File | Typeface | Licence |
| --- | --- | --- |
| `Archivo-SemiExpanded-SemiBold.ttf` | [Archivo](https://fonts.google.com/specimen/Archivo), semi-expanded width, weight 600 (nearest to the site's headings) | [SIL Open Font License 1.1](https://openfontlicense.org) |
| `Archivo-Regular.ttf` | Archivo, normal width, weight 400 | SIL Open Font License 1.1 |
| `IBMPlexMono-Medium.ttf` | [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono), weight 500 | SIL Open Font License 1.1 |

Downloaded from Google Fonts as TrueType.
